ZANACO PERSONAL FINANCE APP — LOGOUT FIX
========================================

WHY LOGOUT MAY NOT BE WORKING
Your repository has a logout.js script and /api/logout endpoint, but the
dashboard pages may not be loading logout.js. This upload updates the
Cloudflare Pages middleware to load it automatically on all four dashboard
pages. It also keeps cloud-sync.js and the login gate enabled.

UPLOAD
1. Extract this ZIP.
2. In GitHub, open Zaza93-crypto/zanaco-personal-finance-app.
3. Open the functions folder.
4. Upload the provided _middleware.js and commit it to the same branch
   Cloudflare Pages deploys.
5. Wait for the deployment to finish.
6. Open the website, hard refresh/reload, and check for the Log out button.

IMPORTANT
- If functions/_middleware.js already exists, download a backup first.
  This file replaces that middleware, so merge existing middleware logic
  rather than overwriting it if it contains other important logic.
- The repository should already contain root files logout.js and
  cloud-sync.js, plus functions/api/logout.js and functions/api/sync.js.
- This ZIP has not been deployed to GitHub or tested on the live site.
- If clicking Log out still fails after this deploy, inspect the browser
  Network tab for POST /api/logout. A 404 suggests the Pages Function route
  isn't deployed; a 500 suggests a function/runtime issue.

All Money / Zanaco Personal Finance App — Add a Logout button

This ZIP adds a visible Log out button to the existing dashboard pages. It uses the existing POST endpoint at /api/logout, which clears the allmoney_session cookie, and then redirects to login.html.

Files:
- logout.js

Upload:
1. Extract the ZIP.
2. Upload logout.js to the repository ROOT (same level as index.html, budget.html, investment.html, tracker.html).
3. In each of these four files — index.html, budget.html, investment.html, tracker.html — add this line just before </body>:
   <script src="/logout.js" defer></script>
4. Commit the changes to main and wait for Cloudflare Pages to deploy.
5. Open the dashboard and confirm the Log out button appears at the top-right. Tap it; it should sign out and return to login.html.

Important:
- Do not replace or delete your existing pages or database tables.
- The existing logout API route is functions/api/logout.js and accepts POST requests.
- This adds a small fixed-position button; it does not change your dashboard layout or financial records.

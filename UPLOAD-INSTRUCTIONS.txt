UPLOAD
1. Open the repository on GitHub.
2. Open cloud-sync.js and choose Edit (pencil icon).
3. Replace the complete contents with the cloud-sync.js file in this ZIP.
4. Commit the change to the branch Cloudflare Pages deploys (normally main).
5. Wait for the Cloudflare Pages deployment to succeed.
6. On both devices, sign in to the same account and refresh the dashboard.

This keeps the four existing pages and the current Cloudflare Pages + D1 architecture. It does not change database tables or overwrite the HTML pages.

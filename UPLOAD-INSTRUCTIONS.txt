Zanaco Personal Finance App — PBKDF2 compatibility fix

The error says the current password hashing requests 210,000 PBKDF2 iterations, but this Cloudflare runtime supports at most 100,000.

Upload ONLY:
functions/_lib/auth.js

Steps:
1. Extract this ZIP.
2. In GitHub open functions/_lib/auth.js.
3. Replace the entire file with the included auth.js (keep the path exactly; do not add a nested folder).
4. Commit to main and wait for Cloudflare Pages deployment.
5. Try creating the account again.

The same hashPassword function is used by registration and login, so both will use 100,000 iterations. This change does not alter D1 tables or the four dashboard pages.

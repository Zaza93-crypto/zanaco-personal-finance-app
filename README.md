# All Money — Personal Finance Website (Redesign)

## Files
- `index.html` — Overview dashboard
- `tracker.html` — Financial tracker, demo add-transaction form, filters and statement file selection
- `budget.html` — Budget planner and create-budget form
- `investment.html` — Investment tracker and add-investment form
- `style.css` — Shared responsive styling based on the supplied reference image
- `script.js` — Small client-side interactions

## Deploy
Upload all six files to the same folder in your GitHub repository, preserving the filenames. If replacing an existing site, make a backup first. Deploy the repository through your existing Cloudflare Pages project.

## Important
This is a front-end starter/demo. Data entered is held in the current page session and is not synced between devices. PDF/Excel/CSV selection is implemented, but parsing bank statements, authentication, cross-device sync, and persistent storage need to be connected to your existing backend (for example, your Cloudflare D1/API). The example figures are sample dashboard content, not live account data.

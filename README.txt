ZANACO / ALL MONEY REDESIGN ASSETS

This ZIP contains the shared design assets fetched from the current GitHub repository:
- all-money-redesign.css
- all-money-redesign.js

IMPORTANT: This is not the completed four-page HTML ZIP. The repository's HTML files were read successfully, but GitHub rejected the attempt to write updated HTML files with a 403 permission error. Therefore this package does not pretend to contain modified index.html, tracker.html, budget.html, or investment.html.

To use these assets, each of the four HTML files must include the CSS link before </head>:
<link rel="stylesheet" href="/all-money-redesign.css?v=20261016">

And the JavaScript link before </body>:
<script src="/all-money-redesign.js?v=20261016"></script>

Do not overwrite your existing HTML with this package.
